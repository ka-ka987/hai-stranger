# 桌面赛博小猫入门项目

这是一个给新手练手的最小版本：启动后，屏幕上会出现一只透明背景的小猫，它会自己走动、停下、睡觉，可以点击、拖动，也可以右键打开菜单。

## 第 1 步：安装 Node.js

去 Node.js 官网下载安装 LTS 版本：

https://nodejs.org/

安装完成后，重新打开终端，输入：

```bash
node -v
npm -v
```

能看到版本号，就说明安装好了。

## 第 2 步：安装项目依赖

进入这个项目文件夹后运行：

```bash
npm install
```

这一步会安装 Electron。

## 第 3 步：启动小猫

运行：

```bash
npm start
```

你应该会看到小猫出现在桌面上。

## 第 4 步：先体验功能

- 小猫会自己左右走动
- 点击小猫会变开心
- 按住小猫可以拖动
- 右键小猫可以喂食、睡觉、退出

## 第 5 步：把占位猫换成真实猫

第一版的猫是用 CSS 画出来的。等你跑通后，可以准备透明背景的真实小猫素材，比如：

- 透明 GIF
- 透明 WebM 视频
- PNG 序列帧

然后把 `src/index.html` 里的猫身体结构替换成图片或视频：

```html
<img id="cat" class="cat" src="./assets/cat-walk.gif" alt="桌面小猫" />
```

对应地，把素材放到：

```text
src/assets/cat-walk.gif
```

## 推荐学习顺序

1. 先跑通现在这个版本
2. 改小猫颜色、大小、速度
3. 添加更多菜单项
4. 换成真实猫 GIF
5. 增加不同动作素材
6. 再考虑加语音、聊天、提醒等 AI 功能
